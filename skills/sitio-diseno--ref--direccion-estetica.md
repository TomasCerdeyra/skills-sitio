# Reference: Dirección estética

**Etapa 1 del flujo.** Definir el tono visual del proyecto antes de tocar código. Sin esta decisión clara, los componentes terminan siendo genéricos.

## Tonos visuales — repertorio

Elegir UNO. No mezclar. Cada uno tiene una "firma" reconocible.

### Editorial
- Inspiración: revistas impresas, The New York Times, Apartamento Magazine.
- Tipografía: serif display + sans-serif body. Mucho contraste.
- Layout: columnas claras, márgenes generosos, alineaciones precisas.
- Cuándo: skincare premium, restaurantes con narrativa, librerías, estudios profesionales.

### Bold / Brutalist moderno
- Inspiración: archivos de diseño suizo + Web3 design.
- Tipografía: sans-serif extra bold, mezcla con monospace.
- Colores: contrastes fuertes, paletas saturadas.
- Borders gruesos, sombras duras (no blur), transformaciones agresivas en hover.
- Cuándo: marcas de ropa urbana, agencias creativas, productos digitales.

### Cálido / Orgánico
- Inspiración: cafés, productos artesanales, marcas locales.
- Tipografía: serif suave + sans-serif redondeada (geometric humanist).
- Colores: tierras, beiges, mostazas, verdes oliva. Saturación baja.
- Bordes redondeados, formas orgánicas (blobs, círculos), texturas sutiles.
- Cuándo: panaderías, cafés, productos artesanales, cosmética natural.

### Geométrico / Minimal
- Inspiración: Bauhaus, diseño escandinavo.
- Tipografía: sans-serif geométrica precisa.
- Colores: paleta restringida (3 colores max), uso fuerte del blanco.
- Líneas, círculos, cuadrados como elementos compositivos.
- Cuándo: estudios contables, consultoras, marcas de tecnología, joyería minimalista.

### Retro / Nostálgico
- Inspiración: posters años 70, vintage typography.
- Tipografía: display tipo grotesque vintage (Cooper, ITC Avant Garde, Zilla Slab).
- Colores: paletas de la época (mostaza + naranja + crema, o burdeos + mostaza + verde oliva).
- Texturas (grain, noise sutil), bordes irregulares.
- Cuándo: heladerías, peluquerías retro, marcas con storytelling vintage.

### Tech / Futurista
- Inspiración: Linear, Vercel, Stripe.
- Tipografía: sans-serif monoespaciada para acentos + sans humanist.
- Colores: oscuros con acentos eléctricos (cyan, púrpura, lima).
- Glow effects sutiles, gradientes mesh, líneas finas.
- Cuándo: SaaS, productos digitales, marcas tech.

### Lujo / Hospitality
- Inspiración: hoteles boutique, marcas de moda alta gama.
- Tipografía: serif display refinada (Didot-style) + sans-serif elegante.
- Colores: negro + dorado, o cremas + verdes oscuros profundos.
- Mucho espacio en blanco, animaciones lentas y suaves.
- Cuándo: restaurantes premium, joyerías, hoteles, peluquerías de alta gama.

### Vibrante / Pop
- Inspiración: marcas DTC de Instagram (Glossier, Allbirds early days).
- Tipografía: sans-serif friendly + display chunky.
- Colores: pasteles + saturados, gradientes alegres.
- Ilustraciones simples, formas redondeadas, animaciones bouncy.
- Cuándo: skincare juvenil, marcas para mujeres jóvenes, productos lifestyle.

## Cómo elegir según rubro + objetivo

| Rubro | Objetivo: confianza | Objetivo: acción inmediata | Objetivo: explorar |
|---|---|---|---|
| Restaurante / bar | Editorial / Cálido | Bold | Cálido |
| Skincare | Editorial / Vibrante | Vibrante | Editorial |
| Estudio profesional (contable, legal) | Geométrico / Editorial | Geométrico | Editorial |
| Ropa urbana | Bold / Brutalist | Bold | Bold |
| Ropa elegante | Lujo / Editorial | Lujo | Lujo |
| Productos artesanales | Cálido | Cálido | Cálido |
| Tech / SaaS | Tech | Tech | Tech |
| Heladería / panadería | Cálido / Retro | Vibrante | Cálido |
| Joyería | Lujo / Geométrico | Lujo | Lujo |
| Peluquería / estética | Editorial / Vibrante | Vibrante | Editorial |
| Hospitality (hoteles, posadas) | Lujo / Editorial | Lujo | Editorial |

> Estas son guías, no reglas. El instinto del diseñador puede romperlas si tiene buena justificación (ej: una panadería con identidad brutalist puede ser memorable).

## La "marca visual" del proyecto

Decisión obligatoria: **¿qué elemento único va a tener este sitio que no tenga ningún otro?**

Opciones:
- **Un trazo personalizado** — una línea curva, un subrayado dibujado, un underline animado en headings.
- **Un patrón** — pattern SVG repetido en backgrounds de secciones (waves, dots, grain).
- **Una textura** — papel, ruido, gradient mesh.
- **Un detalle de borde** — esquinas cortadas, bordes irregulares, dashed elegantes.
- **Una transición específica** — los headings se revelan letra por letra, las imágenes hacen flip al hover, los botones tienen un splash.
- **Una "zoom box"** — productos que al hover ZOOM-IN dramático con shadow brutal.
- **Un elemento decorativo recurrente** — un asterisco, una estrella, un símbolo del rubro (espiga para panadería, tijera para peluquería) que aparece en headings, dividers, etc.
- **Un layout asimétrico distintivo** — Heroes de 60/40 con un overlap, grids con 1 elemento más grande siempre en posición fija.

**Comprometerse con UNA opción.** Aplicarla consistentemente en todo el sitio.

## Validación antes de avanzar a Etapa 2

Antes de empezar con tipografía y colores, responder por escrito:

```
Tono visual elegido: {ej: "editorial cálido"}
Por qué: {ej: "el cliente vende productos artesanales con narrativa de origen, necesita transmitir cuidado y oficio"}
Marca visual del proyecto: {ej: "underlines dibujados a mano debajo de los headings principales, hechos con SVG path"}
Tema: {claro / oscuro / mixto}
```

Sin este compromiso explícito, **no avanzar**. El resto del flujo depende de esta decisión.
